# Code of Conduct

BDownloader follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming, whatever someone's experience, background or
  identity.
- Discuss code and ideas, not people. Give and accept constructive feedback.
- No harassment, insults, trolling, or publishing others' private information.

Maintainers may remove comments, commits, issues or contributions that break
these rules, and may block repeat offenders.

To report a problem privately, contact the maintainer through their GitHub
profile ([berguitta](https://github.com/berguitta)). Reports are handled
confidentially.
